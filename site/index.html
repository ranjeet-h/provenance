DESIGNED AROUND CONTEXT

Overlap is a place to start reading.

A shared phrase can have many explanations: a common prompt, familiar terminology, a quotation, or collaboration. Provenance puts the matched text beside its source so an educator can review what the surrounding work says.

Compare the submissions and reference materials you select. A match helps direct attention; the educator brings the context and makes the decision.

LOCAL BY DESIGN

A private workspace for student writing.

Review assignments without sending student writing to an online analysis service. Keep your sessions on your device, and share only the reports or reference packs you choose to export.

Local storage is not a substitute for device security. Protect student data, backups, and any reports you export.

RUN IT ON YOUR MACHINE

Build the desktop app from source.

Install Node.js, pnpm 12.3.3, Rust, and the Tauri system dependencies for your OS. Then start the app from the repository root.

Read the full setup guide

The current desktop preview is available as source; public installers are not available yet.

# Security

There are no versioned public releases yet. Security reports should target the
current default branch, `master`.

## Report a vulnerability

Please use GitHub's **Report a vulnerability** feature in this repository's
Security tab. Do not disclose a suspected vulnerability in a public issue or
discussion before the maintainers have had a chance to investigate it.

Do not include real student submissions, names, or other personal data in a
security report. Use synthetic examples where possible.
